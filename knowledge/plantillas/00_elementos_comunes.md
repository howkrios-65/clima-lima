# Elementos comunes de todo informe

| Elemento | Contenido |
|---|---|
| Resumen ejecutivo | La decisión recomendada primero, la evidencia mínima suficiente y el riesgo residual |
| Leyenda de evidencia | VERIFICADO / SOLO-SNIPPET / NO-VERIFICADO / SÍNTESIS / CÁLCULO / SUPUESTO / VACÍO |
| Cada afirmación numérica o causal | Fuente (archivo, URL o DOI), nivel de evidencia y, si es cálculo, el script; sin cita se elimina o se marca "sin evidencia" |
| Pie de reproducibilidad | Hash o snapshot de los datos con fecha, versión del kit, semillas, parámetros, versiones de librerías |
| Supuestos y vacíos | Lista explícita; ningún vacío se rellena con una estimación sin marcar |
| Anexo de pendientes | Normas con "edición no verificada", fuentes SOLO-SNIPPET a re-verificar |
| Figuras | Una sola paleta (un color de acento para lo más crítico y una familia de grises o azules), fondo blanco, ejes con unidades, n y fuente en el pie |
