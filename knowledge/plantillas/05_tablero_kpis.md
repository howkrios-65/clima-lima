# Plantilla: tablero de KPIs

| Campo por KPI | Contenido |
|---|---|
| Nombre y decisión que dispara | Si no dispara una decisión, no entra al tablero |
| Definición y fórmula | Con fuente y nivel de evidencia; si las fuentes discrepan, se muestra la definición adoptada y por qué |
| Fuente de datos y consulta | Versionada, con fecha de corte |
| Unidad y calendario base | Calendario o programado; unidades de tiempo |
| Calidad de datos | Porcentaje de órdenes sin código de falla, sin costo, sin fecha |
| Trampas aplicables | Censura en MTBF, paradas planificadas, MTTR con o sin demora logística, disponibilidad de OEE distinta de la de confiabilidad |
| Meta | Solo con fuente, o rotulada "convención local" |
